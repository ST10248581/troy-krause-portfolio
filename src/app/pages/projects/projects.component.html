Night Sky — OTP Verification Component

A production-ready OTP verification UI that solves the fiddly UX problems most implementations get wrong — auto-advancing inputs, clipboard paste support, clean state management and smooth animations. Built in Angular 17 with dark/light theming and glassmorphism design.

This project came out of a real frustration: most OTP input components feel broken. Backspace doesn't work the way you expect, pasting a code from your clipboard fails, and the focus jumps around unpredictably. I spent six hours getting every edge case right so the experience feels seamless — the kind of detail that users never notice when it works, but immediately notice when it doesn't.
